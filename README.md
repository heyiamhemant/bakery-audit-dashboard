# Bakery Audit — Live Dashboard

A single-file HTML dashboard with all 311 items and 430 photos baked in.

- Open: <https://heyiamhemant.github.io/bakery-audit-dashboard/>
- All photos are recompressed (max 1024px, JPEG q62) and embedded inline.
- On first visit, the bundled backup is hydrated into your browser's
  IndexedDB. Edits you make afterwards stay local to your browser.
- Use the **Import** button to overlay a fresh full-resolution backup.

The source backup is `bakery-audit-backup-2026-06-03.json` (215 MB raw
camera photos); for size reasons only the compressed copy is shipped here.
